# 全球行业轮动模型方法学说明 v1

## 覆盖范围
- A股：中证一级10行业，以行业ETF与指数作为配置工具。
- 港股：恒生综合行业分类11行业组，目标覆盖港股主板95%以上市值。
- 美股：GICS 11个一级行业，覆盖标普500与纳斯达克100成分股。

## 因子框架
1. 宏观敏感度：增长上/下行 × 通胀上/下行四状态下的行业条件收益。
2. 基本面动能：ROE趋势、卖方盈利预期4周上修/下修、销售净利率同比边际。
3. 资金面/持仓：A股北向/公募超低配/融资余额，港股南向/港股通机构持仓，美股13F/行业ETF资金流。
4. 技术面/估值：6M/12M动量、PB-ROE十年分位、拥挤度。

## 默认权重
- A股：资金面35%、宏观25%、基本面20%、技术估值20%。
- 港股：资金面30%、宏观25%、基本面25%、技术估值20%。
- 美股：资金面15%、宏观25%、基本面35%、技术估值25%。

## 约束与阈值
- 单行业相对基准偏离：超配不超过+15%，低配不低于-10%。
- 拥挤度：换手率分位>90%、波动率突增Z值>1.5或龙头估值溢价>80%触发减分。
- 任一因子层得分超过±2σ时标记“信号过强”。
- 年化换手率目标上限400%。
- 交易日历采用NYSE/SSE/HKEX并集。

## 跨市场共振规则
- 三市场全部超配：纳入高置信度候选行业。
- 两市场超配且第三市场非低配：纳入高置信度候选行业。
- 两市场超配但第三市场低配：列为“二市场共振观察”，需投委会复核。
- 单市场超配：仅作为本地市场配置线索，不作为全球共振主线。

版本化CSV位于 `src/industry_rotation/data/industry_mapping_v1.csv`。该表显式记录A股中证一级、港股恒生综合与美股GICS之间无法一一对应的口径差异。

## 数据源设计
生产环境适配器应优先使用公开免费数据源：OpenBB MCP、FRED、OECD、中证指数公司、恒生指数公司、Wind公开指标与Yahoo Finance。当前仓库包含离线可复现的demo数据生成器，字段结构与生产适配器一致。

## 样本外验证
采用滚动3年训练+1年测试思想，输出Top-3行业相对等权行业基准的命中胜率、平均超额收益和最大回撤。当前CLI在无网络环境中使用确定性demo数据验证输出链路；接入真实数据后复用同一指标函数。

## 敏感性测试记录
- 因子权重：建议围绕默认权重±5个百分点重跑，观察Top-3行业稳定性。
- 拥挤度阈值：建议测试85%、90%、95%三档。
- 基准：市值加权、等权、近5年平均行业权重三档对比。
